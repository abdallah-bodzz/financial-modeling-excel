# Financial Modeling in Excel

This repository contains my hands-on work from the DataCamp course **"Financial Modeling in Excel"**.  
The course simulates a junior analyst role at Streit, a real estate investment trust (REIT), evaluating a potential apartment building acquisition in Downtown Detroit.

## What's inside

- `starter-workbooks/` – original Excel files provided at the start of each chapter
- `chapter-1-financial-modeling/` – completed income statement, cap rate analysis, 10-year forecast, HLOOKUP dynamic exit
- `chapter-2-scenario-analysis/` – (coming soon) sensitivity tables, what-if analysis
- `chapter-3-time-value-of-money/` – (coming soon) PV, FV, NPV calculations
- `chapter-4-capital-budgeting/` – (coming soon) IRR, payback period, investment decisions

## Key skills practiced

- Building income statements (P&L)
- Cap rate valuation for real estate
- Forecasting revenue with growth rates
- Dynamic lookups using `HLOOKUP()`
- Color‑coding best practices (blue inputs, black calcs, green sheet refs, red external links)
- Named ranges and absolute references
