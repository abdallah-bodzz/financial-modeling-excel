# Financial Modeling in Excel

This repository contains my complete hands-on work from the DataCamp course **"Financial Modeling in Excel"**.  
The course simulates a junior analyst role at Streit, a real estate investment trust (REIT), evaluating a potential apartment building acquisition in Downtown Detroit.

## What's inside

- `starter-workbooks/` – original Excel files provided at the start of each chapter
- `chapter-1-financial-modeling/` – income statement, cap rate analysis, 10-year forecast, HLOOKUP dynamic exit
- `chapter-2-scenario-analysis/` – scenario manager, goal seek, one/two-variable data tables, sensitivity analysis
- `chapter-3-time-value-of-money/` – ROI calculations, FV(), PV(), benchmark testing
- `chapter-4-capital-budgeting/` – NPV(), XNPV(), IRR(), XIRR(), project comparison

## Key skills practiced

**Chapter 1 – Financial Modeling**
- Building income statements (P&L) from scratch
- Cap rate valuation for real estate (NOI / Property Value)
- Forecasting revenue with growth rates (Previous × (1 + Rate))
- Dynamic lookups using `HLOOKUP()`
- Color‑coding best practices (blue inputs, black calcs, green sheet refs, red external links)
- Named ranges and absolute references (`$A$1`)

**Chapter 2 – What-if Analysis**
- Scenario Manager – creating, switching, and comparing multiple scenarios
- Goal Seek – reverse engineering inputs to hit target outputs
- Data Tables – one‑variable and two‑variable sensitivity analysis
- Conditional formatting with color scales for readability

**Chapter 3 – Time Value of Money**
- Return on Investment (ROI) = Total Return / Investment Amount
- `FV()` – future value of money growing at a given rate
- `PV()` – present value of future cash flows discounted back
- Benchmark testing against target rates

**Chapter 4 – Capital Budgeting**
- `NPV()` vs `XNPV()` – why XNPV is more precise (daily compounding, actual dates)
- `IRR()` vs `XIRR()` – finding the discount rate where NPV = 0
- `EOMONTH()` – generating date ranges for time series analysis
- Golden rule: choose the project with higher NPV, not higher IRR

## Final takeaways from the course

- Financial models are only as good as your assumptions
- `XNPV` and `XIRR` > `NPV` and `IRR` when you have actual dates
- The golden rule of capital budgeting: NPV over everything
- Color coding saves your sanity when models get complex
- Goal Seek feels like cheating but it's just math
